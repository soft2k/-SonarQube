SonarQube

Внешняя обработка для 1С для стандартизации кода через сервис SonarQube

Данная доработка делалась для второй группы внедрения Диадок

После того как нашу группу обязали проверять наш код в доработка через сервис SonarQube, была придумана данная внешняя обработка
Чтобы не пользоваться другими сервисами для загрузки доработок

Внешняя обработка может запускаться на любой базе

Тестировалась на версии 3.27.1508

Работает как на обычных, так и на управляемых формах
